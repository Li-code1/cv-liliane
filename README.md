## 🎯 Sobre o Projeto

Este projeto é uma **Landing Page responsiva e otimizada para conversão**, desenvolvida como parte do meu portfólio focado em Front-End. O objetivo foi aplicar e consolidar conhecimentos em design de interface (UI) e experiência do usuário (UX) básica, garantindo que a página seja acessível em diferentes dispositivos.

A página promove o currículo de Liliane Lima 

## ✨ Funcionalidades

* **Design Responsivo:** Layout que se adapta perfeitamente a telas de desktops, tablets e smartphones.
* **Formulário de Contato:** Inclui um formulário para captação de leads.
* **Validação em JavaScript:** Implementação de lógica básica em JS para validar se os campos obrigatórios foram preenchidos antes do envio.
* **Call-to-Action (CTA):** Botões e seções destacados para maximizar a taxa de conversão.

## 💻 Tecnologias Utilizadas

| Tecnologia | Descrição |
| :--- | :--- |
| **HTML5** | Estrutura semântica e acessível da página. |
| **CSS3** | Estilização, layout responsivo utilizando Flexbox e Grid. |
| **JavaScript** | Implementação de funcionalidades interativas e validação de formulários. |
